# Dastaan-e-Comrade website

Static GitHub Pages website for Dastaan-e-Comrade by M. Umar Shahzad.

## Publish
Upload the contents of this folder to the root of your GitHub repository, keeping `index.html` at the root and the `assets` and `book` folders intact. Then enable GitHub Pages from the `main` branch and `/ (root)`.

## Important
Replace `YOUR-GITHUB-USERNAME` in `robots.txt` and `sitemap.xml` with your actual GitHub username after you know your Pages URL.
